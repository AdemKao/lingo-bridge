> [!CAUTION]
> **Experimental, unsigned alpha.** Not a validated LINE call translator.
> Only test with consenting participants; never rely on this app for
> emergency, medical or safety-critical interpreting.

equivalent to a trusted publisher identity. Do not broadly disable
OS protections to run experimental builds.

## Changes in alpha.2

- **New input diagnostics:** independently test the physical microphone
  and LINE's incoming virtual cable for roughly one second, viewing RMS
  and peak levels. The diagnostic does not write recordings or send data
  to OpenAI/Ollama.
- Existing cable-output test tone, cloud BYOK and local text translation remain.

## Source-only experimental work

- Chinese **Matcha-TTS** ONNX adapter and Japanese Supertonic speech synthesis.
- Chinese↔Japanese one-shot WAV processing with **SenseVoice STT**,
  local **Ollama text translation**, and local TTS.
- See [offline WAV guide](https://github.com/AdemKao/lingo-bridge/blob/main/docs/offline-wav-pipeline.md).

**These source-only CLI tools are not bundled with the desktop app and do
not implement realtime offline LINE call translation.**

## Before testing

- Install and manually configure **two separate** virtual audio cables:
  [routing guide](https://github.com/AdemKao/lingo-bridge/blob/main/docs/audio-routing.md).
- Ask your test partner for consent and use headphones to reduce feedback.
- First verify the LINE outbound test tone and incoming level meter.
- Cloud translation requires a **user-supplied OpenAI API Key (BYOK)**
  and may incur charges. No developer API key ships with the installer.
- Local Ollama **text-only** preview is offline after download, while LINE calls
  themselves still need network connectivity.

## Known gaps

Real LINE call audio capture/playback, latency and translated voice quality
have **not yet passed real-device acceptance testing**. Virtual cable setup
is manual. Offline *live* voice translation, Apple notarization,
production signing, and automatic updates remain incomplete.
