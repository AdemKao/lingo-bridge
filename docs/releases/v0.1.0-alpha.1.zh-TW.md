# Lingo Bridge v0.1.0-alpha.1 — 第一個公開測試版本

[English](v0.1.0-alpha.1.md) · **繁體中文**

> [!CAUTION]
> **本版本僅供開發與測試，尚未驗證真實 LINE 雙向通話翻譯。**
> 請勿將它當成穩定的即時口譯工具。通話雙方必須知悉並同意 AI 音訊處理。

## 下載檔案

在 Release 頁面下方 **Assets** 選擇符合電腦的安裝檔：

| 平台 | 檔案 | 注意事項 |
| --- | --- | --- |
| Windows 10/11 x64 | `.exe` | NSIS 安裝包，未正式簽章 |
| Mac Apple Silicon（M 系列） | `aarch64.dmg` 或 `arm64.dmg` | 非 Apple 正式公證 |
| Mac Intel | `x64.dmg` 或 `x86_64.dmg` | 非 Apple 正式公證 |

Release 同時包含 `SHA256SUMS.txt`，可驗證下載檔案是否完整。

## 本版新增

- Rust／Tauri 2 桌面程式、音訊裝置選擇、測試音和字幕。
- 雲端即時翻譯原型，可讓使用者輸入自己的 **OpenAI API Key（BYOK）**。
  安裝包不包含開發者金鑰或已填寫的 `.env`。
- 各方向的來源／目標語言選擇、原始語音直通設定。
- 本地 Ollama **文字**模型管理與離線文字翻譯預覽。
- 原始碼中提供獨立 SenseVoice STT 和日文 TTS **CLI 實驗程式**，
  但尚未接入桌面即時通話。

## 初次測試條件

1. 自行安裝**兩條相互獨立的虛擬音訊線路**；安裝檔沒有附帶驅動。
2. LINE 麥克風選 Cable A 的錄音端、LINE 喇叭選 Cable B 的播放端。
3. Lingo Bridge 傳出音訊選 Cable A 播放端、收到音訊選 Cable B 錄音端，
   再選你的實體麥克風與耳機。
4. 先播放 **0.5 秒測試音**確認路由，不需消耗 API 費用。
5. 雙方明確同意後，才能啟動雲端音訊翻譯。

詳細說明：[音訊設定](https://github.com/AdemKao/lingo-bridge/blob/main/docs/audio-routing.md)
與[隱私／BYOK](https://github.com/AdemKao/lingo-bridge/blob/main/docs/privacy.md)。

## 已知限制

- 目前必須手動設定音訊裝置，並非 LINE 官方整合。
- 尚未完成雙向語音品質、延遲、回音與各裝置的 LINE 真機驗證。
- Windows 未正式簽章、macOS 未正式公證，系統可能顯示安全警告。
- 完整中日雙向離線語音翻譯尚未完成。
- 目前沒有正式簽署的自動更新機制，Alpha 版功能可能不相容。
- 不適合緊急救援、法律、醫療或其他高風險口譯用途。
