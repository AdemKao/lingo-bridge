# Lingo Bridge v0.1.0-alpha.1 — 實驗性測試版

[English](v0.1.0-alpha.1.md) · [繁體中文](v0.1.0-alpha.1.zh-TW.md)

> **⚠ 這是 Alpha 測試版，尚未完成 LINE 真實通話驗證，請勿當作穩定產品。**
> 僅供技術測試；AI 處理通話前須讓雙方知情並取得同意。
> 本專案並非 LINE／LY Corporation 官方提供或認可的外掛。

## 安裝包

| 平台 | 在 GitHub Release 的 Assets 下載 |
| --- | --- |
| Windows 10／11 x64 | `.exe` NSIS 安裝程式 |
| Mac Apple Silicon | arm64 `.dmg` |
| Mac Intel | x64 `.dmg` |

**安全提示：** Windows 可能出現 SmartScreen 警告；Mac 安裝包尚未經 Apple Developer ID
正式簽章及公證，可能被 Gatekeeper 阻擋。請勿大範圍關閉系統安全功能；
對安全要求較高的環境可先從原始碼編譯或等待正式簽章版本。

## 本版特色

- Rust、Tauri 2 桌面架構與音訊裝置選擇。
- 雙向 AI 語音翻譯、即時字幕的實驗性管線。
- 收、發方向語言設定及原始音訊直通選項。
- 使用者自備 OpenAI Key（BYOK），預設僅在工作階段使用，不儲存至硬碟。
- Ollama 本地**文字**翻譯預覽與模型下載。
- sherpa-onnx 的 SenseVoice STT／日文 TTS CLI 實驗，**尚未接入桌面即時通話**。

## 使用與費用

1. 自行安裝並手動設定**兩組獨立虛擬音訊線路**：
   [音訊設定指南](https://github.com/AdemKao/lingo-bridge/blob/main/docs/audio-routing.md)。
2. 找願意一起測試的通話對象，先透過 App **測試音**驗證 Cable A。
3. 雲端語音需使用者自己的 OpenAI API Key，**本 App 不提供免費 API 額度**。
4. Ollama 本地文字模式需先下載模型，之後文字推論可在本機進行；
   LINE 通話本身仍需要網路。

## 已知限制

- **尚未完成真實 LINE 雙向語音翻譯的裝置驗證。**
- 不含虛擬音訊驅動，也不會自動調整 LINE 音訊選項。
- 回音、延遲及原始語音誤傳仍需確認。
- 中文離線 TTS、完整本地語音翻譯尚未完成。
- 不支援自動更新，尚無正式簽章及公證。
- 不包含外部模型權重，第三方模型另有授權條款。
