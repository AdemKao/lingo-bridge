# Lingo Bridge v0.1.0-alpha.2 — 音訊診斷測試版

[English](v0.1.0-alpha.2.md) · [繁體中文](v0.1.0-alpha.2.zh-TW.md)

> [!CAUTION]
> **實驗性未正式簽章 Alpha，不代表 LINE 雙向通話已通過驗證。**
> 僅供知情同意的測試者使用，不可作為緊急、醫療等高風險口譯工具。

## 安裝檔

在下方 **Assets** 選擇：

| 平台 | 檔名 | 安全狀態 |
| --- | --- | --- |
| Windows x64 | `lingo-bridge-v0.1.0-alpha.2-windows-x64.exe` | 未正式簽章 |
| Mac Apple Silicon | `lingo-bridge-v0.1.0-alpha.2-macos-arm64.dmg` | 臨時簽署，**未經 Apple 公證** |
| Mac Intel | `lingo-bridge-v0.1.0-alpha.2-macos-x64.dmg` | 臨時簽署，**未經 Apple 公證** |

SHA256SUMS.txt 可以檢查檔案完整性，但不等於 Apple 或 Windows 信任發行者。
不建議為了安裝測試程式而關閉系統安全防護。

## 本版新增

- 桌面版增加**實體麥克風及 LINE 接收音訊線路**的手動音量測試：
  按下後只量測約一秒，顯示 RMS 與峰值；不儲存音訊，也不傳送到 AI。
- 原本的 LINE 輸出測試音、雲端 BYOK 與本地文字翻譯功能仍保留。

## 僅原始碼提供的實驗功能

- 中文 Matcha-TTS ONNX 合成、日文 Supertonic 合成。
- 中日雙向 WAV 語音辨識 → 本機 Ollama 翻譯 → 中文／日文語音合成。
- [離線 WAV 操作指南](https://github.com/AdemKao/lingo-bridge/blob/main/docs/offline-wav-pipeline.md)。

**這些是 CLI 開發工具，沒有隨桌面安裝檔提供，也尚未能離線翻譯 LINE 即時通話。**

## 測試之前

- 先設定**兩條獨立**虛擬音訊線路：[設定指南](https://github.com/AdemKao/lingo-bridge/blob/main/docs/audio-routing.md)。
- 告知通話對方並取得同意，使用耳機避免回音。
- 優先測試 LINE 輸出短音及 LINE 接收音量。
- 雲端翻譯需要使用者自己的 OpenAI Key，可能產生 API 使用費。
- Ollama 文字翻譯首次下載後可離線推論，但 LINE 通話仍需網路。

## 已知限制

LINE 真實通話收發、延遲與翻譯品質仍需 Windows／Mac 真機驗證；
虛擬音訊設備需要手動安裝。本地即時語音翻譯、Apple 公證、
正式簽章及自動更新仍未完成。
