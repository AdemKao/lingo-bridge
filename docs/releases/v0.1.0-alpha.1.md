## Download / supported machines

| Platform | Download from the Assets section |

**Unsigned preview:** Windows SmartScreen may warn. macOS installers are not
Developer ID signed or Apple notarized and may be blocked by Gatekeeper. Do not
disable system security protections broadly; build from source or wait for signed
releases if your organization requires trusted installers.

## Highlights

- Rust + Tauri 2 Windows/macOS desktop foundation with audio input/output selection.
- Experimental AI speech translation in two directions and live subtitle events.
- Outbound and inbound language controls and optional original-audio passthrough.
- User-supplied OpenAI API Key (BYOK), used per session and not saved by default.
- Local Ollama **text-only** translation preview and explicit model download.
- Separate local sherpa-onnx SenseVoice STT / Japanese TTS CLI prototypes, not integrated
  into the desktop live translation path.

## Setup and costs

1. Install and manually configure **two independent virtual audio cables**:
   see [Audio routing guide](https://github.com/AdemKao/lingo-bridge/blob/main/docs/audio-routing.md).
2. Connect with a consenting test caller. Verify Cable A using the **test tone**
   before enabling translation.
3. For cloud voice, bring your **own OpenAI API key**. The app does **not** provide
   free API credit; your provider bills usage to your account.
4. Local text models require Ollama and a model download. After download, Ollama
   local text inference needs no cloud model API; your LINE call itself still uses
   the network.

## Known issues and unverified areas

- **No real-device end-to-end LINE bilingual call acceptance test has passed yet.**
- The app does not install or automatically configure virtual audio drivers.
- Speech latency, echo feedback and original-audio leakage require verification.
- Full local voice translation and Mandarin offline TTS are not ready.
- No auto-update, formal code signing or notarization.
- Model distribution is subject to individual provider licenses; no weights are bundled.
