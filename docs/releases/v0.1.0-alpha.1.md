# Lingo Bridge v0.1.0-alpha.1 — First public test preview

[English](v0.1.0-alpha.1.md) · [繁體中文](v0.1.0-alpha.1.zh-TW.md)

> [!CAUTION]
> **Developer preview only. Native LINE two-way call translation is NOT validated.**
> Treat this as a test release, not a safe or reliable live interpreting product.
> Both participants must know and consent to any AI processing of call audio.

Choose the installer for your computer from **Assets** below:

## What's included

- Rust/Tauri 2 desktop application with audio device selector, test tone and subtitles.
- Cloud realtime translation prototype with a **user-supplied OpenAI API key** (BYOK).
  The app does **not** ship a developer API key or populated `.env`.
- Choice of source/target languages and optional pass-through of original speech.
- Local Ollama **text** model management and offline text translation preview.
- Optional SenseVoice STT and Japanese TTS **separate CLI research tools**
  available in the source repository (not integrated into the installers' call path).

## Requirements and first test

1. Install **two independent virtual audio cables** separately; none is bundled.
2. Configure LINE microphone → Cable A recording endpoint and LINE speaker → Cable B playback endpoint.
3. Configure Lingo Bridge outbound → Cable A playback; incoming → Cable B recording;
   physical microphone → mic; output → headphones.
4. Play the built-in **0.5-second test tone** to verify outgoing routing without API cost.
5. Only enable cloud translation with the informed consent of both participants.

Full instructions: [Audio routing guide](https://github.com/AdemKao/lingo-bridge/blob/main/docs/audio-routing.md).
Privacy: [BYOK and consent](https://github.com/AdemKao/lingo-bridge/blob/main/docs/privacy.md).

## Known issues and limitations

- Audio routing is manual; automatic LINE integration is not provided.
- Real LINE call compatibility, bidirectional quality, latency and echo isolation require testing.
- Windows installers are unsigned. macOS installers are not Apple Developer ID signed/notarized,
  so the operating system may display warnings or block installation.
- No complete offline Chinese↔Japanese speech-to-speech pipeline yet.
- No signed auto-update channel; this alpha may change without backward compatibility.
- Please don't use the app for emergency, safety-critical, legal or medical interpreting.
