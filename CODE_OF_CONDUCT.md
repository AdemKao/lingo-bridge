# Community Code of Conduct

We welcome people contributing to audio accessibility, machine translation,
cross-platform Rust development and documentation.

Please be respectful and constructive in all Issues, Pull Requests and reviews.
Harassment, threats, personal attacks, discriminatory language, sharing private
communications without permission, and posting credentials or personal
information are not acceptable.

Keep technical disputes focused on reproducible evidence. When reporting failures
in real calls, use synthetic examples instead of exposing another person's
audio or messages.

If you experience abuse or a security issue, contact the maintainer through
GitHub's private reporting/contact mechanisms where available. Avoid publishing
sensitive evidence in a public issue. Maintainers may remove harmful content
and restrict participation.
